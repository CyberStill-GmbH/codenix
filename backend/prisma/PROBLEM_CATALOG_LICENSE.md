# Codenix problem catalog

The 150 seeded problems are original Codenix educational content. Their titles,
stories, explanations, examples, generated inputs, and expected outputs were
written for this repository and are not copied from a third-party problem bank.
The underlying algorithmic ideas are standard programming concepts.

This approach follows the U.S. Copyright Office guidance that copyright does
not protect ideas, procedures, processes, methods of operation, mathematical
principles, or algorithms, while the particular written expression can be
protected: <https://www.copyright.gov/help/faq/faq-protect.html>.

The catalog is generated by `prisma/generated-problem-catalog.ts` and loaded by
`npm run seed:problems`. Hidden test cases are stored in the database with
`visibility = hidden`; public problem and submission endpoints do not expose
their input or expected output.
