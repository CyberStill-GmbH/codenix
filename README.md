## El producto

Codenix reúne el ciclo completo de práctica algorítmica en una experiencia clara: descubrir un problema, desarrollar una solución, ejecutarla contra casos de prueba y revisar el resultado. Cada envío conserva sus veredictos y métricas para que el aprendizaje sea visible a lo largo del tiempo.

La plataforma incluye:

- Catálogo de problemas con dificultad, temas, ejemplos y límites de ejecución.
- Espacio de resolución con plantillas por lenguaje y ejecución de prueba.
- Envíos evaluados, historial de resultados y detalle por caso de prueba.
- Perfil y estadísticas de progreso, incluido el estado de problemas resueltos.
- Administración de problemas, casos de prueba y recursos asociados.
