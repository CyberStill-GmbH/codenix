# J-010: Hoja de ruta del juez

**Estado:** Propuesto

## Secuencia

1. Consolidar contratos de lenguaje, casos publicados y pruebas de integración.
2. Medir y corregir memoria máxima, tiempos y limpieza de recursos.
3. Extraer workspace y sandbox sin modificar API ni cola.
4. Introducir el contexto y pipeline cuando las pruebas de regresión cubran el flujo actual.
5. Evaluar caché de compilación o pooling solo con datos de carga reales.

## Fuera del alcance inmediato

Judge interactivo, checkers personalizados, proyectos multifichero y ejecución distribuida requieren un ADR, modelo de amenaza y coste operativo antes de entrar al roadmap comprometido.
