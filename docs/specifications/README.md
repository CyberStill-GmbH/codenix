# Especificaciones

Las especificaciones describen requisitos verificables de componentes. A diferencia de los ADR, no justifican una decisión transversal: definen el comportamiento, límites y criterios de aceptación de una parte concreta del producto.

## Estado

- **Estable**: guía el comportamiento actual y los cambios deben respetarla.
- **Propuesto**: diseño aprobado como dirección, pendiente de implementación o validación.
- **Archivado**: conservado como contexto; no prescribe trabajo nuevo.
