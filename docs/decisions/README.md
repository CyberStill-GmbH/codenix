# Decisiones arquitectónicas

Los Architecture Decision Records (ADR) mantienen el contexto de decisiones que afectan más de un componente. Un ADR se agrega cuando una elección cambia límites de confianza, persistencia, operación, contratos o coste de mantenimiento.
